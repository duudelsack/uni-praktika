# Praktika aus dem Studium

Ausgewählte Praktika aus dem Bachelor Künstliche Intelligenz an der HAW Landshut. Die größeren Projekte haben eigene Repositories: [salary-prediction](https://github.com/duudelsack/salary-prediction), [klimawandel-analyse](https://github.com/duudelsack/klimawandel-analyse), [stroke-prediction](https://github.com/duudelsack/stroke-prediction) und [real-vs-ai-image-classification](https://github.com/duudelsack/real-vs-ai-image-classification).

| Ordner | Fach | Semester | Inhalt |
|---|---|---|---|
| `programmieren-1/twitter-trends/` | Programmieren 1 (Python) | 1 | Stimmung von Tweets nach Bundesstaat auf einer Karte der USA |
| `data-science-1/praktika/` | Data Science 1 | 1 | Datenaufbereitung am Housing-Datensatz: fehlende Werte, Ausreißer, Korrelationen, Transformer |
| `programmieren-2/` | Programmieren 2 (Java) | 2 | Grundlagen (Spiralen, Monte-Carlo-Integration), Arrays und Strings mit Tests, Spiel Sirius Journey, Slot-Machine, Prozessoren und Zinsrechner mit JUnit-Tests |
| `datenbanken/jeopardy/` | Datenbanken | 3 | Jeopardy-Spiel in Java mit SQLite |
| `sicherheit/vigenere/` | IT-Sicherheit | 3 | Vigenère-Verschlüsselung in Python |

## Hinweise

- Twitter Trends baut auf einem Projektgerüst der UC Berkeley (CS 61A) auf.
- Das Jeopardy-Spiel braucht den SQLite-JDBC-Treiber (`sqlite-jdbc`) im Klassenpfad.
