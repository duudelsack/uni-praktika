# Praktika aus dem Studium

Übungen und Praktika aus dem Bachelor Künstliche Intelligenz an der HAW Landshut. Die größeren Projekte haben eigene Repositories: [salary-prediction](https://github.com/duudelsack/salary-prediction), [klimawandel-analyse](https://github.com/duudelsack/klimawandel-analyse), [stroke-prediction](https://github.com/duudelsack/stroke-prediction) und [real-vs-ai-image-classification](https://github.com/duudelsack/real-vs-ai-image-classification).

| Ordner | Fach | Semester | Inhalt |
|---|---|---|---|
| `programmieren-1/` | Programmieren 1 (Python) | 1 | Python-Labs, Übungen und das Projekt Twitter Trends: Stimmung von Tweets auf einer Karte der USA |
| `data-science-1/` | Data Science 1 | 1 | Praktika zu pandas und Datenaufbereitung, Housing-Datensatz, Beispielanalyse Ringgröße mit Cross-Validation |
| `data-science-2/` | Data Science 2 | 2 | Clustering (Mall Customers), Praktika, Klassifikation von Bewegungsdaten (Gehen und Laufen) |
| `programmieren-2/` | Programmieren 2 (Java) | 2 | Praktika zu Grundlagen, Objektorientierung, Arrays und Strings, Slot-Machine mit Tests |
| `datenbanken/` | Datenbanken | 3 | Jeopardy-Spiel in Java mit SQLite |
| `sicherheit/` | IT-Sicherheit | 3 | Vigenère-Verschlüsselung in Python |

## Hinweise

- Das Jeopardy-Spiel braucht den SQLite-JDBC-Treiber (`sqlite-jdbc`) im Klassenpfad.
- Twitter Trends baut auf einem Projektgerüst der UC Berkeley (CS 61A) auf.
